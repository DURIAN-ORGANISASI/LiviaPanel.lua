# Security policy

## Scope

Livia Panel is a single-file client-side Roblox Lua script. The source should be reviewed before use, especially when copied into another tool or execution environment. The repository does not provide a dedicated security support SLA.

## Reporting a concern

Please do not post passwords, tokens, private game data, or a detailed security issue in a public issue.

If GitHub's private vulnerability reporting feature is enabled for this repository, use it to send details privately. If it is not available, open a public issue containing only a request for a private reporting channel; do not include exploit details or sensitive data in that issue.

## Safe-use guidance

- Read `LiviaPanel.lua` before running it and verify that the copy came from this repository.
- Do not enter Roblox passwords, cookies, authentication tokens, or other account secrets into scripts or third-party executors.
- Use the script only in experiences you own or in environments where its use is explicitly authorized. Do not use its movement or collision controls to cheat in other creators' experiences.
- The optional raw-loader snippet downloads and executes source code. Inspect the source first and do not run remote code you have not reviewed.

Roblox's official [Cheating and Exploiting guidance](https://en.help.roblox.com/hc/en-us/articles/203312450-Cheating-and-Exploiting) explains that cheating or exploiting violates Roblox's Terms of Use and can lead to account deletion.
